# Number Guessing Game

A simple Python number guessing game where the computer chooses a random number and the player tries to guess it.

## Features

- Generates a random number
- Allows the user to enter guesses
- Checks whether the guess is correct
- Tells the user if the guess is too high or too low
- Simple and beginner-friendly Python project

## Technologies Used

- Python
- Random module

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python project.py
